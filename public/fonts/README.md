# Optional custom fonts

This complete source archive does not redistribute font binaries. The app works with built-in system-font fallbacks.

For the original typography, add copies of the following font resources from **your own original Portfolio project** to this directory, if you have the rights to use them:

- `AtAero-Light.woff2`
- `AtAero-Regular.woff2`
- `AtAero-Medium.woff2`
- `AtAero-Semibold.woff2`
- `AtAero-Bold.woff2`
- `FiraCodeNerdFont-Regular.ttf`

The `style/optional-fonts.css` declarations will automatically use them. No edits are needed.
